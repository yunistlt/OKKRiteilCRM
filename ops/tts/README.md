# TTS-сервер (озвучка Тамары)

Синтез русской речи моделью **Silero v4_ru** на своём железе. Бесплатно,
без внешних ключей, без DPI — по тем же причинам, что и свой STT-сервер
(см. `lib/transcribe.ts`).

Голос Тамары — **`kseniya`** (выбран прослушиванием 23.09.2026).

## Контракт

```
POST /tts     {"text": "...", "speaker": "kseniya", "format": "ogg"}
              -> audio/ogg  (ogg/opus — формат голосовых Telegram)
              -> audio/wav  при format=wav
GET  /health  -> {"status":"ok","model":"v4_ru","speakers":[...]}
```

Текст длиннее 900 символов сервер сам дробит по границам предложений и
склеивает аудио — отчёты Тамары в один запрос укладываются целиком.

## Установка

```bash
pip install torch fastapi uvicorn
apt-get install -y ffmpeg          # обязателен для format=ogg
python3 -m uvicorn server:app --host 0.0.0.0 --port 8081
```

Первый запрос тянет модель (~60 МБ) в `~/.cache/torch/hub` и потому идёт
дольше остальных. Дальше модель живёт в памяти процесса.

## Проверено

Прогон 23.09.2026, macOS, CPU, 4 потока: вечерний разбор на 700 символов →
42 с речи за 5,4 с, то есть ~8× быстрее реального времени. Задержка для
раза в сутки несущественна.

`format=ogg` на машине разработки не проверялся — там не было ffmpeg.
Первым делом после установки на сервере прогнать:

```bash
curl -s -X POST localhost:8081/tts -H 'Content-Type: application/json' \
  -d '{"text":"Проверка связи.","format":"ogg"}' -o /tmp/t.ogg && file /tmp/t.ogg
```

## Переменные

| Переменная     | По умолчанию | Смысл                        |
|----------------|--------------|------------------------------|
| `TTS_SPEAKER`  | `kseniya`    | голос по умолчанию           |
| `TTS_THREADS`  | `4`          | потоков torch на CPU         |

Со стороны приложения адрес сервера — `TTS_URL` (по образцу `STT_URL`).

## Грабли

- **Цифры.** Silero читает «42» хуже, чем «сорок два». Нормализация чисел в
  слова — на стороне приложения, до вызова сервера, а не здесь.
- **ffmpeg.** Без него `format=ogg` отдаёт 500. Telegram принимает голосовым
  сообщением только ogg/opus; wav уедет файлом, а не голосовухой.

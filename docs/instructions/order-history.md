# История заказа

В карточке заказа есть кнопка **«История»** — она показывает, что по заказу
менялось: статусы, комментарии, состав, поля, суммы. Две вкладки: «Изменения
статуса» — только переходы по этапам, «Изменения заказа» — всё подряд. В
таблице видно старое значение, новое, кто поменял и когда.

## Почему у старых заказов история короткая

Заказы живут у нас с 2015 года, а подробную историю из RetailCRM мы начали
переносить с 1 января 2025 года. У всего, что раньше, перенеслись только
смены статуса — комментариев менеджера, правок состава и прочего в ОКК не
видно, хотя в RetailCRM они есть.

Пример: по заказу 32321 от ноября 2023 года у нас было 5 записей, а в
RetailCRM — 66, с перепиской по датам и причиной отмены.

## Как дотянуть историю по конкретному заказу

Откройте карточку заказа, нажмите **«История»**, а в открывшейся панели —
**«Скачать историю из ритейла»**. Через несколько секунд рядом с кнопкой
появится ответ: сколько записей добавилось и сколько уже было. Таблица
обновится сама.

Качать заранее по всем заказам не нужно — только когда история по заказу
кому-то понадобилась.

Что важно знать:

- **Ничего не затирается.** Записи, которые уже есть в ОКК, не меняются.
  Добавляются только те, которых у нас нет.
- **Нажимать можно сколько угодно.** Второй раз ответит «новых записей нет».
- **Свои заказы ОКК скачать нельзя** — их в RetailCRM никогда не было, и
  кнопка об этом прямо скажет.
- **Звонки кнопка не тянет** — только историю изменений заказа.

## Если кнопка ответила ошибкой

«RetailCRM не ответила» — старая система недоступна или закончилась лицензия.
Повторите позже, а если повторяется — скажите Андрею: после отключения
лицензии история останется только та, что уже скачана к нам.

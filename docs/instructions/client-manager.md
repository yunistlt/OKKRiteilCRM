# Менеджер клиента

У каждой карточки клиента есть менеджер — тот, кто ведёт этого покупателя
сейчас. Он виден в карточке первым блоком, «Менеджер клиента».

## Зачем это важно

От менеджера карточки зависят задачи «напомнить о себе»: бот-РОП кладёт их в
план дня тому, за кем закреплён клиент. Если клиент давно работает с другим
человеком, а в карточке остался прежний, чужая работа попадает в чужой план —
так в план Елены попал клиент, которого ведёт Ирина.

Заказы тут ни при чём: по одному клиенту заказы могут вести разные менеджеры, и
задача всё равно уходит владельцу карточки.

## Как сменить

Откройте карточку клиента и выберите менеджера в списке. Сохраняется сразу,
подтверждать ничего не нужно. В списке только действующие сотрудники: клиент не
должен достаться уволенному.

Можно оставить «Не закреплён» — тогда задач по этому клиенту не будет никому.
Это не норма, а временное состояние: клиент без менеджера — клиент, которому
никто не позвонит.

## На деньги это не влияет

Смена менеджера карточки не трогает премии по уже оформленным заказам:
зарплата считается по менеджеру на момент продажи. Передача клиента меняет
только то, кому дальше идут задачи и звонки по нему.

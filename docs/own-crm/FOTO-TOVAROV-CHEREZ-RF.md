# Фото товаров — через российский сервер

## Что произошло

Сайт `zmktlt.ru` отвечает только российским адресам. Проверка 06.10.2026:

| Откуда | Картинка `.../49166.750x0.jpg` |
|---|---|
| мак владельца (Испания) | соединения нет вовсе |
| наш сервер `zeh2` (Россия) | HTTP 200, 20 797 байт, `image/jpeg` |

ОКК собирается на зарубежном сервере, поэтому:

* в карточке заказа фото товара не грузилось;
* **в КП клиенту уходила пустая колонка «Фото»** — молча, без ошибки: сборщик
  PDF просто пропускает картинку, которую не смог забрать (проверено сборкой
  КП с недоступным адресом — файл собрался, фото исчезло).

## Решение

Адрес фото подменяется на наш сервер в России, он ходит за картинкой сам.
Подменяются **только** медиафайлы магазина (`/wa-data/`) и только у хостов
`zmktlt.ru` / `www.zmktlt.ru`. Открытого прокси нет.

Код: `lib/own-crm/catalog-image.ts`, включается переменной
`CATALOG_IMAGE_PROXY_BASE`. Переменная не задана — адрес остаётся прежним, и в
России всё работает напрямую, как раньше.

## Что сделать на сервере zeh2

1. Бэкап: `cp /root/zeh/deploy/Caddyfile /root/zeh/deploy/Caddyfile.bak-$(date +%Y%m%d-%H%M%S)`
2. В секцию `erp.zmksoft.ru`, **перед** строкой `reverse_proxy app:8080`, вставить:

```
	# Фото товаров сайта zmktlt.ru для ОКК: сайт пускает только российские
	# адреса, а ОКК собирается на зарубежном сервере (разбор 06.10.2026).
	# Пропускаем ТОЛЬКО /wa-data — папку медиафайлов магазина; открытого
	# прокси не делаем.
	handle /wa-data/* {
		reverse_proxy https://www.zmktlt.ru {
			header_up Host www.zmktlt.ru
		}
		header Cache-Control "public, max-age=86400"
	}
```

3. Проверить и применить:

```
docker exec zeh-caddy caddy validate --config /etc/caddy/Caddyfile
docker exec zeh-caddy caddy reload --config /etc/caddy/Caddyfile
```

4. Убедиться, что картинка отдаётся:

```
curl -o /dev/null -w "%{http_code} %{size_download} %{content_type}\n" \
  https://erp.zmksoft.ru/wa-data/public/shop/products/61/85/28561/images/49166/49166.750x0.jpg
```

Ожидается `200 20797 image/jpeg`.

## Что сделать в Vercel

Добавить переменную окружения и передеплоить:

```
CATALOG_IMAGE_PROXY_BASE=https://erp.zmksoft.ru
```

До этого момента ОКК работает как раньше — подмены нет.

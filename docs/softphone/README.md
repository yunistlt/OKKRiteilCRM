# Телефон в интерфейсе (softphone)

Менеджер звонит и видит входящие прямо в CRM. Разговор идёт на его обычном
телефоне (добавочный Телфина), приложение показывает статус, историю и карточку
звонящего — как в RetailCRM. Звук в браузер не передаётся.

## Как устроено

**Исходящий.** Кнопка → `POST /api/calls/initiate` → `initiateManagerOutgoingCall`
(`lib/telphin.ts`) → Телфин звонит на добавочный менеджера и на клиента, соединяет.
Статусы приходят вебхуком и разлетаются по SSE в открытые панели.

**Входящий.** Телфин → `POST /api/calls/webhooks/incoming` → матчинг заказа по
номеру (`lib/call-matching.ts`) → `broadcastCallEvent` → панель показывает, кто
звонит и по какому заказу. Трубку менеджер снимает на аппарате.

Запись и расшифровка — прежний конвейер Телфина, ничего не меняли.

## Файлы

| Что | Где |
|---|---|
| Звонок менеджера через Телфин | `lib/telphin.ts` → `initiateManagerOutgoingCall` |
| Рассылка событий по SSE | `lib/call-broadcast.ts` |
| Начать звонок | `app/api/calls/initiate/route.ts` |
| История звонков | `app/api/calls/history/route.ts` |
| Поток событий (SSE) | `app/api/calls/subscribe/route.ts` |
| Панель телефона | `components/softphone/PhonePanel.tsx` |

| Подписка на события | `lib/hooks/useCallNotifications.ts` |

Панель подключена в `app/layout.tsx` и показывается только вошедшему
пользователю. Свёрнутая — кнопка «Телефон» в правом нижнем углу.

## Данные

Пишем в существующие таблицы: `outgoing_calls`, `incoming_calls`,
`raw_telphin_calls`. Новых таблиц звонков не заводили.

Миграция `migrations/20260903_softphone_setup.sql` добавляет
`managers.telphin_extension` — добавочный менеджера в Телфине. Без него звонок
не уйдёт: система не знает, какой аппарат поднимать.

```bash
node scripts/apply-softphone.mjs          # применить миграцию
node scripts/setup-manager-extensions.mjs # проставить добавочные ОП (105/119/120)
```

Права: `/api/calls` открыт ролям admin, okk, rop, manager (`lib/rbac.ts`).

## Ключи Телфина

```
TELPHIN_APP_KEY, TELPHIN_APP_SECRET          # обязательны, иначе демо-режим
TELPHIN_CALLBACK_CALLER_ID=74993504490       # номер, который видит клиент
```

Первое плечо звонка — добавочный самого менеджера, очередь 200 не используется
(она для обратного звонка Ловца Лидов и подняла бы весь отдел).

Без ключей `/api/calls/initiate` отвечает `mock: true` и честно пишет в панели,
что реальный звонок не совершён. Локально в `.env.local` ключей нет — они на
Vercel, поэтому по-настоящему позвонить можно только с прода.

## Чего нет

Звук в браузере (WebRTC), перевод звонка на другого менеджера, hold/mute из
интерфейса — всё это управляется аппаратом и требует отдельной интеграции.
Панель рассчитана на десктоп.

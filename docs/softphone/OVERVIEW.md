# Телефон в интерфейсе (softphone) — as-built

Менеджер звонит и видит входящие прямо в CRM. Разговор идёт на его аппарате
(добавочный Телфина), интерфейс показывает статус, карточку звонящего и историю.
Звук в браузер не передаётся — WebRTC тут нет.

В проде с 03.09.2026, ветка `feat/softphone`, влито в main.

## Поток

**Исходящий.** Кнопка → `POST /api/calls/initiate` → `initiateManagerOutgoingCall`
(`lib/telphin.ts`) → Телфин поднимает добавочный менеджера и набирает клиента.

**Входящий.** Телфин → `POST /api/calls/webhooks/incoming` → матчинг заказа по
номеру (`lib/call-matching.ts`) → `broadcastCallEvent` → карточка в панели.
Проверено только на исходящих; входящие вживую не гоняли.

Запись и расшифровка — прежний конвейер Телфина, не трогали.

## Грабли (все три стоили времени — не наступать снова)

**1. Очередь ≠ добавочный.** Первым плечом (`src_num`) должен идти добавочный
САМОГО нажавшего. Если поставить очередь ОП 200 (как в обратном звонке Ловца
Лидов) — Телфин поднимет весь отдел разом, и с клиентом соединится случайный
человек. Поймали до боевого теста.

**2. `TELPHIN_MOCK_MODE=true` живёт в env Vercel.** Эндпоинт его СОЗНАТЕЛЬНО не
читает: менеджер нажал кнопку — значит хочет живой звонок. Так же ведёт себя
воркер обратного звонка. Демо-режим остаётся только когда нет ключей Телфина.
Симптом, если вернуть чтение флага: панель пишет «Демо-режим», абоненту тишина.

**3. Добавочный берётся по менеджеру из сессии, а не по человеку.** Учётка
`admin` Андрея привязана в CRM к менеджеру **999 «Системный Администратор»**, а
не к 102 «Теренков Андрей» — поэтому добавочный проставлен обоим.

## Данные

Пишем в существующие `outgoing_calls` / `incoming_calls` / `raw_telphin_calls`.
Новых таблиц звонков не заводили. Миграция `20260903_softphone_setup.sql`
добавляет `managers.telphin_extension` — без него звонок не уйдёт.

```bash
node scripts/apply-softphone.mjs          # миграция
node scripts/setup-manager-extensions.mjs # добавочные (сейчас только Андрей)
```

Пока обкатываем — добавочный стоит только у Андрея (108). У ОП снят намеренно:
чужой аппарат от чужого клика звонить не должен. Открывать отделу — раскомментировать
список в скрипте.

## Софтфон на рабочем месте

Добавочный — это SIP-аккаунт, звонку нужно устройство. На Маке Андрея стоит
**Linphone** (`/Applications/Linphone.app`, поставлен вручную из dmg — Homebrew
на машине нет).

SIP-данные берутся в кабинете Телфина: карточка сотрудника → «Данные для
настройки SIP-оборудования» (НЕ «Логин и пароль пользователя» — тот пароль для
кабинета и расширения Chrome, для SIP не подходит). Логин `12037*108`, сервер
`corp.telphin.ru`, порт 5060, транспорт UDP. По SRV `_sip._udp` Linphone уходит
на 5068 — это нормально.

**Телфин не пускает SIP-регистрацию с зарубежных IP.** Linphone при этом врёт:
показывает «Username and password do not match», хотя в логе
`~/Library/Application Support/linphone/logs/linphone1.log` лежит настоящий
ответ `SIP/2.0 403 Forbidden Ip`. Пароль сервер даже не проверяет. При любом
отказе регистрации — сразу читать этот лог, а не менять пароли.

Обход для работы из-за границы — WireGuard через московский VPS, см.
`ops/reverse-proxy/README.md`.

## Чего нет

Звук в браузере, перевод звонка, hold/mute из интерфейса — всё на аппарате.
Панель под десктоп. Статус и длительность в истории остаются на «Набор»: Телфин
не шлёт вебхуки о завершении звонка (та же болячка у обратного звонка Ловца
Лидов). Записи и расшифровки при этом собираются штатно.

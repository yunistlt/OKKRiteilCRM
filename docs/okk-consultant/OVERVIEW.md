# Семён — как сделано (as-built)

**Читать первым** при возврате к теме: план развития лежит в
[PLAN.md](PLAN.md) и [EVOLUTION.md](EVOLUTION.md), а здесь — что в проде
сегодня и на чём уже обжигались. Дата снимка: 03.11.2026, сборка `1c6d116b`.

## Что это

Помощник внутри ОКК. Не справочник: отвечает на вопросы по заказам, клиентам,
плану дня, зарплате, правилам ОКК и устройству самого сервиса, а также делает
дела — ставит задачи, готовит письмо и звонок.

Где живёт в интерфейсе: правая колонка, под планом дня
(`components/GlobalConsultantShell.tsx`). Разговор сворачивает план в плашку.
Вопрос уходит по Enter. Экраны без колонки: `/login`, мессенджер, аналитика,
штаб.

## Путь запроса

`app/api/okk/consultant/route.ts` — единственная дверь:

1. **Мета** (кто спрашивает, роль, номер менеджера). Без номера менеджера
   отключаются «мои» инструменты: зарплата, рейтинг, мой день, действия.
2. **Знания** — два слоя параллельно:
   - `okk_consultant_knowledge` — инструкции для людей и определения
     (порог 0.50, не больше 4 попаданий);
   - `project_knowledge` — куски документации репозитория (порог 0.33).
3. **Модель с инструментами** решает сама, откуда брать ответ, и зовёт нужные
   (до 30 кругов).
4. **Ответ** — и в журнал `okk_consultant_logs`.

**Перехватов больше нет.** Статьи разделов, критерии, формулы и термины едут
подсказками (`referenceNotes`), а не ответом вместо модели.

## Модель

`gpt-5.5`, рассуждающая, в двух местах одновременно:
`DEFAULT_CONSULTANT_PROMPTS` в `lib/okk-consultant-ai.ts` **и** таблица
`ai_prompts`. Правка только в одном месте не доезжает: `npm run
okk:consultant-seed-kb` переписывает таблицу из кода.

## Инструменты

| Инструмент | Откуда данные |
|---|---|
| `order_dossier`, `orders_find` | наши `orders` + карточка клиента |
| `client_dossier` | `clients`, сделки считаем, а не читаем колонку |
| `day_plan` | `sales_rop_task` |
| `create_order_task` | задачи заказа, только свои заказы |
| `team_grades` | `salary_grade` + расклад из `salary_grade_eval.detail` |
| `salary_*`, `rating_*`, `my_day_*` | только при номере менеджера |
| `code_*` | снимок кода `project_code_file` |
| `draft_client_email`, `call_client` | кладут действие в `assistant_actions` |
| `calc` | арифметика вместо устного счёта модели |

## Письмо и звонок — через подтверждение

Семён **не отправляет**. Действие ложится в `assistant_actions` со статусом
«ожидает подтверждения», человек нажимает кнопку в `PendingActions` (над полем
ввода чата и в телефонной панели). Выполняет `/api/assistant/actions`, и только
своё: действие привязано к номеру менеджера. Механизм общий с ботом-РОПом,
второго нет.

## Грабли (все проверены на живом проде)

1. **Модель не знает, какое сегодня число.** Без явной даты в промпте считала
   год 2023 и отвечала «зарплата за октябрь 2023».
2. **gpt-5.5 не принимает `reasoning_effort` вместе с инструментами** в
   `/v1/chat/completions` — 400. В ветке с инструментами передаём `'none'`.
3. **Справочник отвечал вместо модели.** «Напиши клиенту письмо» совпадало с
   критерием ОКК и возвращало описание критерия за 0 секунд.
4. **Ё и Е.** Статус на доске «В просчете», человек пишет «в просчёте» —
   сравнение в лоб не находит ничего. Сравниваем через `plainLetters`.
5. **Адрес письма нельзя требовать от модели.** Требовали — получали «уточните
   email» при заполненной карточке. Теперь почту и телефон добирает сервер:
   `lib/own-crm/order-contact.ts`, один читатель на все три места.
6. **Снимок кода устаревает молча.** В `scripts/index-project-code.ts` написано,
   что он обновляется на каждой боевой сборке, но в `package.json` строка
   `build` — просто `next build`: подключения нет, и снимок стоял от 23.09.2026.
   Пока обновляется руками: `npm run tamara:index-code` из каталога, равного
   проду, и не в рабочее время — 1934 файла, 13,9 МБ одной транзакцией.

## Как проверять

```bash
npm run okk:consultant-quality-gate    # обязательно перед правкой маршрутизации, промпта, каталога
npm run okk:consultant-regression      # эталоны + бенчмарк
npx vitest run tests/order-contact.test.ts
```

Живьём — вопросами по сети, без интерфейса: сессия подписывается тем же
секретом (`JWT_SECRET`, локально и на проде работает запасной из кода), запрос
POST на `/api/okk/consultant`. Подготовленные проверкой действия удалять по
точному id, иначе они ждут человека в чате.

Известное: `okk:consultant-regression` падает на устаревшем случае про доставку
(статьи с таким названием нет), и ворота качества — на дрейфе эталонов;
`tests/sales-rop.test.ts` при полном прогоне иногда не укладывается в 5 секунд,
отдельно проходит.

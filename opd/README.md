# opd/ — описания образцового положения дел (ОПД)

Один файл на пост: `opd/<пост>.md`. Собирается и обновляется из диктовок
в `raw/`. Дыры и противоречия — в `/QUESTIONS.md`.

Пакет документов по посту (положение, ЦКП, статистики, папка поста)
делается только по отдельной команде, после утверждения ОПД.
